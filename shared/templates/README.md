# `shared/templates/`

Authoring templates that keep the course consistent. Copy one and fill it in.

| Template | Use it to create |
|----------|------------------|
| [`module-template.md`](./module-template.md) | A new teaching module (`NN-module/README.md`). |
| [`lab-template.md`](./lab-template.md) | A hands-on lab (`NN-module/lab/README.md`). |
| [`adr-template.md`](./adr-template.md) | An Architecture Decision Record for a project. |

The module template encodes the course's content model:

```text
Concept → Why it matters → Mental model → Minimal implementation →
Hands-on lab → Production considerations → Common mistakes →
Assessment → Further reading
```

See [CONTRIBUTING.md](../../CONTRIBUTING.md) for the full style guide.
