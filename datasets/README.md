# `datasets/`

Small, static datasets used by labs and notebooks (for example, sample cost
exports for the FinOps modules, or synthetic metrics for observability exercises).

## Conventions

- **Small and synthetic.** Keep files well under a few MB and prefer generated or
  anonymized data. This is a learning repo, not a data store.
- **No real or sensitive data.** Never commit customer data, real billing
  exports, or anything containing secrets or PII.
- **Documented.** Each dataset gets a short note here describing its shape and
  where it's used.

> 🚧 Populated as data-driven modules (observability, FinOps) land.
